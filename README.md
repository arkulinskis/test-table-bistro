# Test Table Bistro

A fake, static restaurant website for testing PlanPlate as a restaurant owner would. Not a real restaurant.

- The whole site is one file: `theme/assets/index.html`. Edit it in the Anvil editor under **Assets**.
- `client_code/startup.py` just loads that file as the page (no forms, no database, no server code).
- The reservation form on the site sends nothing. Replace it with PlanPlate's booking widget.
